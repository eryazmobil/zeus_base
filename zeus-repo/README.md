# zeus-repo

ZeusBaseData kütüphanesinin derlenmiş paketleri (zeus-data, zeus-ui). Kaynak kod içermez.

Bu klasörü elle değiştirmeyin. Yeni sürüm ZeusBaseData projesinde şu komutla gelir:

    ./publish-to-app.sh <bu projenin klasörü> <sürüm>

Ardından `app/build.gradle` içindeki `eryaz.software.zeus:zeus-ui` sürümünü güncelleyip bu klasörü commit'leyin.
